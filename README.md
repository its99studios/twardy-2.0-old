# Unleash Your Imagination!

**Twardy is back in a 2.0 release!**

Twardy 2.0 is a sandbox-survival game made in GDevelop. You are Mark, a survivor of a great incident. Your goal is to save the Mainmap, or just plant seeds. Your choice.

## Controls:

Accessible Controllers: Keyboard \& Mouse, Xbox, PS4

* Player Controls/Actions:

  * Moving:

    * Keyboard: WASD
    * Xbox/PS4: Left stick / D-pad
  * Dropping an item:

    * Keyboard: Q
    * Xbox: LB
    * PS4: L1
  * Planting a seed/eating food:

    * Mouse: Right-click
    * Xbox: RT
    * PS4: R2
  * Punching:

    * Mouse: Left-click
    * Xbox: A
    * PS4: Cross
  * Building:

    * Keyboard: B
    * Xbox: RB
    * PS4: R1

## Development Information:

Twardy 2.0 is being developed using **GDevelop** for the game logic and \*\*Piskel \*\*for the pixel art assets. The music is created with **Chrome Music Lab**, and sound effects with **JFXR**.
